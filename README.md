# ИИ-бот для Telegram (на базе Claude)

## Что делает
Простой Telegram-бот, который отвечает на сообщения с помощью ИИ Groq (модель Llama 3.3 70B, бесплатно).
Хранит короткую историю диалога для каждого чата, есть команда `/reset` для очистки истории.

## Установка

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Откройте файл `.env` и вставьте свой ключ Groq API вместо `вставьте_сюда_свой_ключ_groq`.
   Получить ключ бесплатно: https://console.groq.com/keys (регистрация без карты)

## Запуск

```bash
python bot.py
```

После запуска откройте своего бота в Telegram и напишите `/start`.

## ⚠️ Важно про безопасность

- Токен вашего Telegram-бота уже прописан в `.env`. Никогда не публикуйте этот файл (например, не заливайте на GitHub без .gitignore).
- Поскольку токен был отправлен в чате с ИИ, рекомендуется на всякий случай перевыпустить его:
  1. Откройте @BotFather в Telegram
  2. `/mybots` → выберите бота → `API Token` → `Revoke current token`
  3. Вставьте новый токен в `.env`

## Деплой на Render (бесплатно, работает 24/7)

1. Создайте аккаунт на https://render.com (можно войти через GitHub)
2. Залейте эту папку с кодом в репозиторий на GitHub (или GitLab):
   ```bash
   cd tgbot
   git init
   git add .
   git commit -m "первый коммит"
   git branch -M main
   git remote add origin <ссылка_на_ваш_репозиторий>
   git push -u origin main
   ```
   ⚠️ Перед этим добавьте файл `.gitignore` со строкой `.env`, чтобы токены не попали в публичный репозиторий (см. ниже).
3. На Render: **New** → **Web Service** → подключите ваш GitHub-репозиторий
4. Настройки сервиса:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: Free
5. В разделе **Environment** добавьте переменные (те же, что в `.env`):
   - `TELEGRAM_TOKEN` = ваш токен от BotFather
   - `GROQ_API_KEY` = ваш ключ Groq
   - `PYTHON_VERSION` = `3.12.6` (важно для совместимости библиотек)
6. Нажмите **Create Web Service** — Render соберёт и запустит бота

После деплоя бот будет работать постоянно, без вашего компьютера.

⚠️ **Важно про бесплатный тариф Render:** сервис может "засыпать" при отсутствии входящих HTTP-запросов ~15 минут. Бот использует long polling к Telegram (не HTTP-запросы извне), поэтому *может* засыпать. Если заметите, что бот перестаёт отвечать через какое-то время — самый простой фикс: настроить бесплатный сервис вроде UptimeRobot, который раз в 10 минут дёргает URL вашего Render-сервиса (он покажет "Bot is running") — это не даёт ему засыпать.

### .gitignore
Создайте файл `.gitignore` рядом с ботом:
```
.env
__pycache__/
*.pyc
```

## Настройка под себя

- `SYSTEM_PROMPT` в `bot.py` — задаёт "характер" и инструкции для бота.
- `MODEL` — можно поменять модель Claude.
- `MAX_HISTORY_MESSAGES` — сколько последних сообщений помнит бот.

## Как подключить бота к своему аккаунту

Бот, созданный через @BotFather, — это отдельный аккаунт, с которым можно переписываться,
как с обычным пользователем в Telegram. Просто откройте диалог с ним по ссылке
`t.me/<имя_вашего_бота>` и напишите `/start`. Никакого "подключения" к вашему личному
аккаунту делать не нужно — бот работает независимо и отвечает всем, кто ему пишет.
